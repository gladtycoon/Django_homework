# 🛒 Интернет-магазин (Django)

Проект интернет-магазина, разрабатываемый в рамках курса SkyPro. Проект будет постепенно расширяться и улучшаться на протяжении всего обучения.

## 📋 О проекте

В этом репозитории ведется разработка полноценного веб-приложения интернет-магазина с использованием Django. Каждый урок добавляет новую функциональность, а выполнение домашних заданий гарантирует, что к концу курса у вас будет готовый проект для портфолио.

## 🚀 Технологии

- **Python** — основной язык программирования
- **Django 6.0.3** — веб-фреймворк
- **Poetry** — управление зависимостями
- **SQLite** — база данных (на старте)
- **HTML/CSS** — шаблоны и стили
